# 留言板 · Note Wall

一个干净的在线留言板。写下想说的话，留在这面墙上。

纯前端实现，零依赖、零构建 —— 打开 `index.html` 就能用。

## 功能

- **写留言** —— 昵称可选（留空显示「匿名」），内容最多 500 字，实时字数统计
- **发布** —— 点击按钮或 `Ctrl / ⌘ + Enter` 快捷发布
- **点赞** —— 单设备一票，可取消，点赞状态本地记住
- **删除** —— 只能删除本机发布的留言，删除前二次确认
- **复制** —— 一键复制「昵称：内容」
- **搜索** —— 按内容或昵称过滤，命中关键词高亮
- **排序** —— 最新 / 最热（按点赞数）
- **加载更多** —— 每页 8 条，逐页展开
- **明暗主题** —— 一键切换，跟随上次选择，首屏无闪烁
- **响应式** —— 手机 / 平板 / 桌面自适应
- **导出** —— 一键把全部留言导出为 JSON

## 本地运行

直接双击 `index.html` 可以，但更推荐起一个静态服务器（避免个别浏览器的本地文件限制）：

```bash
# Python 3
python -m http.server 8080

# 或 Node
npx serve .
```

然后访问 <http://localhost:8080>。

## 部署到 GitHub Pages

1. 把仓库推到 GitHub；
2. 进入 **Settings → Pages**；
3. **Source** 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`；
4. 保存后等 1 分钟左右，访问 `https://<用户名>.github.io/<仓库名>/`。

本项目没有构建步骤，因此不需要任何 CI 配置。

## 数据说明

所有留言保存在浏览器 `localStorage` 中，键名：

| 键 | 用途 |
| --- | --- |
| `notewall:notes:v1` | 全部留言 |
| `notewall:liked:v1` | 当前设备点过赞的留言 ID |
| `notewall:owner:v1` | 当前设备的身份 ID（用于判断「我的留言」） |
| `notewall:nick:v1` | 上次使用的昵称 |
| `notewall:theme` | 主题偏好 |

这意味着：

- 数据**不会**跨设备同步，换浏览器或清缓存后会消失；
- 没有服务端，因此不存在账号系统，也无法防止有人通过开发者工具改数据；
- 适合做个人留言墙、活动签到墙、演示项目；如果需要真正的多人共享，需要接一个后端。

想备份就把页面底部的「导出数据」点一下。

## 自定义

- **改配色**：`style.css` 顶部的 CSS 变量，`--accent` 是主色。
- **改字数上限**：`app.js` 里的 `MAX_LEN`，同步改 `index.html` 中 `textarea` 的 `maxlength`。
- **改每页条数**：`app.js` 里的 `PAGE`。
- **改初始示例留言**：`app.js` 的 `seedNotes()`；想清空所有数据，在控制台执行 `localStorage.clear()` 后刷新。
